# 小说分解失败续跑设计

## 目标

- AI 返回缺字段、时间格式错误或信息可见性缺失时，对当前分段自动局部重试。
- 单个分段重试耗尽后记录失败，但继续处理后续分段。
- 全部分段执行结束后统一汇总失败分段和最近错误，不在首个错误处要求人工校对。

## 行为

- 小说分解任务至少提供 3 次自动重试机会；用户设置更高值时尊重更高值。
- 失败分段保持 `失败` 状态，后续调度跳过该分段并继续寻找下一个 `待处理` 分段。
- 一轮批处理内遇到失败不再 `break`，继续处理批次中的后续分段。
- 没有待处理分段但仍存在失败分段时，任务以 `failed` 结束并汇总失败数量、标题和错误。
- 人工校对仍可用于处理最终失败项，但不再是继续执行其他分段的前置条件。

## 验证

- 回归测试覆盖默认重试次数为 0 时仍会自动重试。
- 回归测试覆盖首段失败后后续分段仍会完成。
- 回归测试覆盖任务结束时统一返回失败汇总。
